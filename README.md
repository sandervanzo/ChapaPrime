# ChapaPrime
ChapaPrime é um app desktop para planejamento de corte e dobra de chapas. Calcula BLANK e peso, otimiza cortes 1D com kerf/margem/folga, exibe pré-visualização com cotas e exporta PDF/PNG profissionais. Interface dark, entrada por texto/tabela e relatórios prontos para o chão de fábrica.
